# PlayDesk — информационная система управления игровым центром

Проектная документация учебной практики ПМ.03 «Ревьюирование программных продуктов» (09.02.07 «Информационные системы и программирование»), Колледж ВятГУ, группа ИСПк-404-52-00. Автор: Пастернак С. А.

## Описание работы

В ходе практики выполнена предпроектная и проектная работа над системой автоматизации компьютерного клуба: анализ предметной области, сценарии использования, реестр требований и проверка его полноты, техническое задание по ГОСТ 34.602-2020 и технический проект. Система разрабатывается как конфигурация на платформе **«1С:Предприятие 8.3»** с интеграцией с CRM **«Битрикс24»**.

## Концепция и проблема

**Какую боль решает продукт.** Во многих компьютерных клубах учёт ведётся вручную или в нескольких программах сразу. Из-за этого:

- один и тот же компьютер бронируют дважды, или он простаивает, потому что администратор не видит актуальной занятости;
- время сеансов и продажи бара считаются вручную — отсюда ошибки в кассе и расхождения при инвентаризации;
- заявки с сайта и из мессенджеров приходят в CRM, а учёт ведётся отдельно, поэтому статус брони переносят руками;
- руководитель не может быстро узнать выручку и загрузку залов.

PlayDesk объединяет всё это в одной системе: карта залов, сеансы, брони, продажи, клиенты и отчёты.

**Для кого создаётся:**

- **Администратор (кассир)** — основной пользователь, работает с системой всю смену.
- **Руководитель игрового центра** — смотрит отчёты по выручке и загрузке.
- **Техник** — отмечает неисправное оборудование.
- **Клиенты** — оставляют онлайн-заявки на бронирование через «Битрикс24».

## Основной функционал первой версии

- **Роли и доступ:** авторизация, у каждой роли только свои функции и данные.
- **Кассовая смена:** открытие и закрытие смены со сверкой наличных.
- **Карта залов:** статусы компьютеров — свободен, занят, забронирован, в ремонте.
- **Игровые сеансы:** запуск, продление и завершение с расчётом стоимости по тарифу.
- **Онлайн-бронирование:** приём заявок из «Битрикс24», проверка занятости, ответ обратно в CRM.
- **Продажи бара:** сканер штрихкодов, контроль остатков на складе.
- **Клиенты и лояльность:** клиентская база, скидки, бонусные баллы.
- **Оборудование:** перевод компьютера в ремонт и перенос затронутых броней.
- **Отчёты:** выручка и загрузка залов для руководителя.

## Технологии

1С:Предприятие 8.3 (клиент-серверный режим), PostgreSQL 16, веб-сервер Apache 2.4 (HTTP-сервис для «Битрикс24»), REST API «Битрикс24», система компоновки данных (отчёты), библиотека подключаемого оборудования.
